# Recursos visuales

20 archivos JPG incluidos en assets/stories, optimizados para uso sin conexión. Se crearon cinco hojas originales de cuatro paneles con la herramienta integrada de generación de imágenes durante este desarrollo. Cada hoja conserva el mismo personaje adulto en portada, retrato y escena final. Se separaron los paneles y se exportaron con JPEG calidad 88. No se descargaron imágenes de stock ni se utilizan URLs temporales.

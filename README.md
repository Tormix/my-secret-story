# My Secret Story

Repositorio privado de la aplicación **My Secret Story**.

## Estado actual

- Repositorio inicializado el 19 de noviembre de 2026.
- La última entrega localizada es el APK Android **1.4.9**.
- El código fuente correspondiente a la versión 1.4.9 todavía no está disponible en este repositorio.
- La copia de fuentes 1.4.6 encontrada en Drive es anterior y no debe usarse como versión actual.

## Tecnología prevista

- Expo
- React Native
- TypeScript
- Expo Router

## Preparación de la subida

Cuando esté disponible el proyecto fuente de la versión 1.4.9:

1. Confirmar la versión desde `package.json`, configuración de Expo y notas de entrega.
2. Revisar el árbol completo antes de añadirlo al repositorio.
3. Excluir archivos locales, compilados y dependencias.
4. Buscar y retirar claves, tokens, contraseñas, certificados y credenciales.
5. Sustituir la configuración sensible por variables de entorno documentadas en un archivo `.env.example` sin valores reales.
6. Ejecutar las comprobaciones disponibles (TypeScript, lint y pruebas) antes del primer commit de código.

## Seguridad

- No subir archivos `.env` ni credenciales reales.
- Las claves privadas y las claves de servicios de servidor no deben incluirse en la aplicación cliente.
- Los secretos deben almacenarse en el gestor de secretos del entorno correspondiente.
